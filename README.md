# AI Gym Assistant

## Overview

AI Gym Assistant is a full-stack AI-powered fitness platform that helps users track workouts, count exercise repetitions in real-time using computer vision, receive AI-driven fitness guidance, discover nearby gyms, monitor achievements, and analyze workout performance.

---

## Features

### Authentication

* User Registration
* Secure Login
* JWT Authentication

### AI Workout Trainer

* Real-time Pushup Counter
* Real-time Squat Counter
* Pose Detection using MediaPipe
* Live Form Analysis
* Calorie Tracking
* Workout Timer

### Fitness Dashboard

* Workout Statistics
* Progress Monitoring
* Achievement Tracking
* Leaderboard System

### Gym Recommendation System

* Google Maps Integration
* Nearby Gym Discovery
* Location-Based Recommendations

### AI Features

* Nutrition Assistance
* Workout Recommendations
* Achievement Engine
